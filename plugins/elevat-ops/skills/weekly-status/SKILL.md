# Weekly status report

1. Load `elevat-ops` and read the Current state section of Linear P-ELE-5.
2. Gather from the last 7 days: merged and open PRs (with owning session), closed and new Linear issues, routine runs that failed.
3. Write one page: Shipped, In progress, Blocked (with the single action each needs from Nicole), Next week. Report what you verified; say "not checked" otherwise.
4. Put it in chat. Update only the Current state section of P-ELE-5 if the focus or blockers changed; do not create a new tracker.
